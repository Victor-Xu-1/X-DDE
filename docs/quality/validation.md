# 验证分层与资源边界

[质量规范入口](README.md) · [服务器原生验收](../server-acceptance.md)

## 按风险选择证据

认领问题时确定最高受影响层级，列出必要检查和直接消费者。层级可以叠加；轻量检查不能替代改变科学含义所需的真实验证。现有专项门禁仍适用，全仓库套件仍需明确授权。

| 层级 | 典型改动 | 最低证据与限制 |
| --- | --- | --- |
| 文档与发布元数据 | 规范、链接、版本镜像 | 文件/链接/内容一致性、独立审查、版本规则及其既有 CI；不为文档启动科研任务 |
| 平台与界面 | 生命周期、并发、I/O 上限、请求处理、交互与状态 | 小型真实文件、真实隔离数据库、受控进程和可解释夹具；界面变化另需真实候选浏览器。模拟接口证明交互行为，不证明科学引擎运行 |
| 科学接口与结果解释 | 输入转换、坐标/单位、解析、引擎契约、结果含义 | 有来源的代表性真实输入/输出、精确版本及实际接口对照；必要时执行有界目标引擎。旧 CI 仅证明它实际运行的版本与范围 |
| 算法、数值与科学引擎 | 模型、数值计算、参数语义、方法默认值、科学结论 | 已核实 CPU/GPU 环境、真实代表输入、可信参考、预先定义指标/容差和适用域；必要的正/负例及重复。冒烟成功不等于科学准确性 |

必要科学验证缺失时，候选保持阻塞，不计入有效 PR。可保存补丁与已完成证据，暂缓该项并继续独立的软件打磨；不得让轻量 CI 全绿代替未完成的科学验收。

## 六类高后果风险的定向复查

以下是按改动选择的检查方向，不是当前已存在六类缺陷的断言。先读已有实现和回归，确认现象再登记缺陷；无复现证据时保留为调查假设，不另造平行机制。

1. **提交与恢复：** 同一意图的重复点击、超时重试和重连不产生重复任务；返回后先核实已有任务，迟到回复不抢占新选择。上传续传不能误称科学任务断点续算。
2. **结果来源：** 输入 asset/hash/record/conformer/version、参数、引擎/模型和输出对应同一任务及选中结果；2D 编辑不假定保留结合姿势，分数/单位不串行。
3. **资源与取消：** 字节/记录/并发/时间/输出预算有界；取消后确认实际进程和资源归属，不能停止无关任务或把取消请求当成终止证明。
4. **诊断与恢复操作：** 服务端保留可关联任务/请求/阶段的诊断，用户看到准确且可执行的错误与下一步；遵守既有 UI 契约，不把原始日志、内部 ID 或工程附件堆进研究页面。
5. **升级与数据兼容：** 识别活动任务、状态/模式版本与迁移边界，验证中断/重复迁移和必要备份；回退前确认旧版本能读当前状态，不能用不兼容旧数据库丢弃新研究记录。
6. **关键旅程：** 选代表材料验证准备→审阅→单次提交/状态恢复，或已有结果→确切材料→下一步；按问题测量重复执行、身份不一致、状态延迟或用户阻塞，不用页面数代替端到端成功。

## 执行前的资源检查

- 确认实际运行环境、CPU/GPU、内存、可用磁盘、依赖及模型版本。磁盘或内存快照不能证明具备 GPU、引擎或足够推理能力。
- 明确样本范围、预计耗时/资源/费用、绝对空间需求、运行上限和停止条件；未知项如实记录。
- 核对已有授权，以及代码、模型权重、输入数据和输出各自许可。安装、下载、调用外部服务与真实计算不能互相视为已授权。
- 从最小代表性案例开始，只扩大已证明确有必要的范围；不自动启动全量数据、大型模型、长时间 GPU、付费资源或无界重试。
- 使用隔离状态目录、数据库和输出，限制读取字节数/记录数、请求/进程并发、超时、重试和缓存生命周期。先清理本任务拥有的资源，不中止无关服务。
- 容量不足、许可不明或必要授权缺失时停止依赖步骤，记录恢复条件。不要为维持维护进度强行执行超出能力的计算。

所有者工作站遵守 [AGENTS.md](../../AGENTS.md) 的 E 盘/WSL 存储、只做静态/构建/生命周期/UI 检查及共享环境保护规则。测试套件在 CI，科学推理和 GPU/LLM 验收在获准的目标服务器；不得因本规范复制示例命令就在工作站运行。CI 使用其隔离工作区，不把所有者路径写进算法和运行契约。

## 科学数据和结果不可被展示层替代

- 分开标识输入模板、实验参考、归档原生计算、测试夹具、模拟接口和新计算；下载、安装和模板预设不是计算结果。
- 保留引擎、模型、输入版本/digest、种子、参数、坐标系、单位、失败和限制；记录能复现对照的命令与环境，证据中不含凭据。
- 修改材料生成派生版本，保留原始文件、原子/残基/序列身份和历史。显示简化、缓存、图件导出和动画不能改写科学源文件。
- 不把距离、接触数、置信度或模型分数改名为作用力、实测亲和力或疗效；无结果、缺单位、缺电荷、缺收敛或未知状态保持显式。
- 后端替换先做相同代表输入的对照，核对真实接口、资源、方法适用性及许可；保留回退版本，迁移消费者后才移除旧路径。参见[方法选择](../design/screening-and-del.md)。

## 结果陈述

每项验证单独标记通过、失败、未运行或受阻，写明实际范围。有限样本不能证明零缺陷；一次原生运行不能推广成全项目科学质量。性能主张必须有同环境、同输入、同操作序列的测量；不能用测试条数、截图或构建成功推导「更快」「无泄漏」「科学已验证」。

证据文件保存在 CI 工件或获准的交付位置，Issue/PR 放入足以审查的摘要和链接。不要提交大体积原生结果、私有研究材料、状态数据库或秘密。科学验收的具体命令和已知限制以[服务器验收文档](../server-acceptance.md)及对应模块契约为准。
